~/projects/customer-churn-prediction

Customer Churn Prediction

Telecom analytics

Code ↗

Predicts which telecom customers are about to churn from their contract, billing, and service usage data.

  • Logistic Regression baseline reached 0% accuracy; a class-balanced Random Forest traded a little accuracy for materially better recall on churners, which is the metric that matters for a retention campaign.
  • Found that month-to-month contracts and fiber-optic service correlate with higher churn, while longer contract terms correlate with lower churn — used to shape which customers a retention team should prioritize.
  • Next: XGBoost comparison, hyperparameter tuning, and a Streamlit demo so the model is clickable, not just a notebook.

~/projects/smartsave-ai-wallet

SmartSave AI Wallet

Amrita University Amritapuri Campus Hackathon, Jul 2026

Code ↗

AI-powered budgeting wallet with receipt-verification and protected savings — built in 24 hours leading a 4-person team ("Hackstreet Boys").

  • OCR pipeline (Tesseract + OpenCV) reads receipts; a Gemini-backed verification service classifies each transaction into Essential / Non-Essential / Blocked before it's allowed to touch a protected savings reserve.
  • Full-stack build: Next.js 15 + TypeScript + Tailwind + Zustand on the frontend, an Express API gateway with PostgreSQL + Prisma, and three Python microservices coordinating over MCP.
  • Six-service Docker Compose deployment with atomic, row-locked transaction handling so concurrent writes can't corrupt a balance.

~/projects/skin-lesion-classification

Skin Lesion Classification

4-person research project · ISIC2018 / HAM10000

⏱ Repo publishing soon

Ensemble of CNN backbones for dermatoscopic skin-lesion classification, with Grad-CAM interpretability.

  • Trained and evaluated four backbones (ResNet50, DenseNet121, EfficientNetB0, MobileNetV2) on ISIC2018 and cross-checked generalization on HAM10000.
  • My contribution: data preprocessing and training the ResNet50 and EfficientNetB0 backbones. ResNet50 was the best-performing backbone at 0% accuracy / 0% weighted F1.
  • Grad-CAM used to visualize what each model was actually attending to — not just trusting the accuracy number.

~/research/spiking-cbm

Calibrated Ante-Hoc Concept Bottlenecks for Spiking Vision Backbones

⚗ Active research · experiment phase

Code ↗

Trying to build the first ante-hoc interpretable spiking neural image classifier — a concept bottleneck layer inserted directly into a SpikingResformer backbone, rather than explained after the fact.

  • Literature review found no existing work combining spiking neural networks with concept bottleneck models for vision.
  • Implemented a frozen SpikingResformer-Ti backbone with a LIF membrane-potential hook feeding a 112-concept bottleneck layer (CUB-200-2011 attributes) into a 200-way classification head.
  • Go/no-go probe on the readout signal: spike-rate narrowly beat pre-reset membrane potential (0 vs 0 mean ROC-AUC), which failed the pre-registered significance gate — so the project pivoted to spike-rate as the primary readout rather than forcing a result.
  • Currently training with the corrected readout; no final accuracy numbers yet — this section will update when there's something real to report.
