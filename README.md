# 🌐 P. Manikanta — Personal Portfolio

## 📌 Project Overview

My personal portfolio site, built as a single self-contained HTML/CSS/JS page. It showcases my profile, ML projects, active research, and skills, with a live interactive terminal and a canvas-based background that reacts to scroll and theme.

The goal is to present my work professionally and build an online presence for internship and entry-level data science opportunities.

## 🚀 Features

- Full light/dark theme support (follows system preference, with a manual toggle)
- Animated canvas background (a drifting embedding-field visualization) that re-tints on theme change
- Sections: About, Projects, Research, an interactive Terminal you can type commands into, Skills, Contact
- Live GitHub stats (stars, last push) pulled per-project via the GitHub API
- Scroll-triggered reveal animations, respecting `prefers-reduced-motion`

## 🛠️ Technologies Used

- HTML5, CSS3 (custom properties, no framework)
- Vanilla JavaScript (canvas rendering, IntersectionObserver, GitHub API fetches)
- Google Fonts (Archivo, Instrument Sans, JetBrains Mono)
